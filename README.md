## 👋 About

I'm Sameer — a Senior DevOps Engineer at **NorthBay Solutions** in Lahore, Pakistan, working where
**Infrastructure as Code**, **CI/CD**, and **AWS governance** meet. I design reusable Terraform and
Terragrunt frameworks that standardize provisioning across large AWS estates, wire up delivery
pipelines that make releases boring, and build the observability that keeps those platforms honest.

I came into DevOps through data engineering — I built the Redshift warehouses and Glue/DMS
pipelines before I automated them. That overlap is my edge: I don't just provision the data
platform, I know what it's for.

## 🛠️ What I build

**Cloud Infrastructure &amp; IaC** — Multi-account AWS architecture with reusable Terraform and
Terragrunt modules. Hardened networking: CIDR planning, public/private subnet isolation, VPC
peering, granular Security Groups and NACLs, and least-privilege IAM.

**CI/CD &amp; Release Automation** — Zero-downtime containerized delivery on Amazon ECS Fargate
through GitHub Actions, GitLab CI, and AWS CodePipeline. Repeatable, zero-touch provisioning that
replaces manual release operations.

**Serverless Observability** — Event-driven monitoring built from Lambda, CloudWatch, CloudTrail,
and DynamoDB — log deduplication, alert aggregation, and buffered digests that cut noise instead
of adding dashboards.

**Data Engineering &amp; Governance** — Redshift warehouses, Glue and DMS pipelines, and Athena
over S3 data lakes. Governed access with Lake Formation, DataZone, Tag-Based Access Control
(TBAC), RBAC, and IAM role chaining.
